## 修订内容

### 引用、图标题与链接

修复重命名表截图误引用上一章 Cache 架构图的问题，以及时序修复流程引用缺少 `fig:` 前缀的问题。图号、章节标签统一为带章节前缀的 ASCII 标签；所有 54 次图引用均有目标，220 个标签没有重复。

修正 Vivado 硬件管理器、FPGA 编程完成界面的重复图标题，以及两个工艺角图标题中混入的 LaTeX 标记。图片继续使用原始像素文件，路径明确指定扩展名。

原稿有 5 处 `[教程文档]()` 未填写目标，保留“教程文档”文字并移除空超链接，不猜测地址。修正相关链接表中多余的右括号，将紧贴中文的裸网址整理成可点击、可断行的链接，消除长网址横向溢出。

### 原稿污染、笔误与排版标记

- 第一章 Shell 重定向说明和第六章 AM 目录说明各混入一条带行号的 JSON 文本，属于明显粘贴污染，已从正文移除；原始内容完整保存在修订记录中。
- 恢复被误作 HTML 标签吞掉的 `/home/<user_name>`，将 HTML 提示、加粗和强调整理为原生 LaTeX。
- 将地址映射表中的 HTML 换行恢复为单元格换行。
- 修正 Pixman 名称、目标“引用”/“应用”、第 5 层“位”/“为”、重复“所示”、AM 环境变量说明的重复句式和标点。
- 删除没有对应图片的 Vim 界面指示句，将终端输出称为“示例”。
- 恢复原有列表结构；代码位于列表中时，消除转换器额外写入源码的缩进，列表本身仍负责视觉缩进。

### 代码与明确的知识表述错误

修正 `cd`、`grep`、`man` 命令名缺字；修正 `ls -l` 与 `grep -i` 的说明，删除 `source` 必须拥有执行权限的错误要求，清屏快捷键改为 Ctrl+L。相关行为对照 [GNU Bash 手册](https://www.gnu.org/s/bash/manual/bash.html) 与 [GNU Coreutils 手册](https://www.gnu.org/software/coreutils/manual/html_node/What-information-is-listed.html) 核对。

修正 QEMU 克隆后的目录名与后续 `cd` 命令不一致的问题，将混在 C 程序第一行的 `hello.c` 文件名改为注释，将 C 运算表达式中的排版长横线恢复为减号，清理命令中的不可见排版空格和提示符前多余字母。所有代码调整逐块记录了原文、结果、原因和哈希。

保留 Makefile 的真实 TAB 字符。程序、配置和命令按实际内容标注语言，例如将误标为 INI 的 `/etc/profile` 改为 Shell，将 Kconfig 与终端输出分别识别；SystemVerilog DPI 示例使用 SystemVerilog 高亮。

功耗小节原来的 `I × V × t` 量纲为能量，不能直接作为平均功耗。现以观察时间内对瞬时功率积分再求平均的表达式替换，并同步调整变量定义；翻转功耗的文字说明改为与电压平方成正比，与原公式一致。短路电流产生机制参考 [TI：CMOS Power Consumption and Cpd Calculation](https://www.ti.com/lit/an/scaa035b/scaa035b.pdf)，平均功耗表达式按功率的时间平均定义整理。

上述修订针对可确认的笔误、写法和量纲错误。书中完整 RTL、固件、仿真模型及 EDA 脚本没有在各自工具链中执行功能验证。

### 字体与高亮

程序代码采用 Latin Modern Mono，中文代码文字采用 Fandol 仿宋。目录树、终端日志等纯文本采用随附的 DejaVu Sans Mono，覆盖箱线符号和特殊空格。所有字体均来自 TeX 或工程随附文件，字形选择明确，不依赖 Windows 字体注册。

176 个代码块均显式指定语言，其中 168 个启用语法配色、8 个按纯文本排版。使用 `listings` 与 `xeCJK-listings`，无外部高亮器，无 shell escape。规则与上一本书一致，并加入本书需要的 C++、JSON、C Shell 和 EDA 命令。可独立编译的样张位于 `examples/code-styles.tex`。

## 验收方法

- 对照 Rmd、保存的 TeX 和新工程，核对章节、标题、图表与代码数量、顺序。
- 逐块检查 176 个代码的哈希；对 10 个修改块重放修订记录，确认只有列出的变更。
- 70 个原始资源逐个检查 SHA-256。
- 将修订后的转换基线与最终分章都交给同一 LaTeX 解析器，比较正文、行内代码、公式和有序表格单元格文本；忽略空白与布局控制。12 章全部一致。代码和插图另做独立核验。
- 检查实际 PDF 中的代码字体、彩色文本指令、中文注释和特殊符号；抽查目录树、地址映射表、JSON、EDA Tcl、长 C 程序和新增语言样张。
- 检查 XeLaTeX 日志中的缺字、溢出、引用错误、字体警告和空链接警告。
- 在最终新目录独立编译，检查 `.fls` 构建输入，确认不读取原目录或上一本书。

最终页数、PDF 哈希和构建环境以 `build-summary.json` 为准。当前验收记录中 LaTeX 错误、缺字、横向或纵向溢出、未定义引用、字体及空链接警告均为 0。
